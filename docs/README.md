## 🔄 Mise à jour de la documentation

La documentation doit être maintenue à jour avec chaque évolution du projet. 

Pour contribuer à la documentation :
1. Suivez les conventions de formatage Markdown
2. Incluez des exemples et captures d'écran quand pertinent
3. Maintenez les liens à jour
4. Versionnez les changements majeurs

## 📝 Conventions

- Utilisez le français pour la documentation utilisateur
- Utilisez l'anglais pour la documentation technique/code
- Incluez toujours un sommaire pour les documents > 2 pages
- Utilisez des diagrammes (Mermaid, PlantUML) pour clarifier les concepts
- Datez et versionnez les documents importants
